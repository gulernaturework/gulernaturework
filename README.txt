ÖNEMLİ:
Bu V2 henüz gerçek çok-kullanıcılı online yönetim sistemi değildir. localStorage kullanır.
Gerçek yayında telefondan eklenen ilanların bütün ziyaretçilere görünmesi için Supabase/Firebase benzeri online veritabanı + dosya depolama bağlanmalıdır.

Ücretsiz sonuca giden önerilen yol:
1) GitHub hesabı aç.
2) Bu klasörü GitHub repository olarak yükle.
3) Cloudflare Pages ile repository'yi bağla.
4) Supabase ücretsiz proje oluştur.
5) İlan/kategori verilerini Supabase'e taşı ve görselleri Storage'a yükle.
6) Yönetici girişini Supabase Auth ile güvenli hale getir.
7) Cloudflare Pages'te siteyi yayınla.
